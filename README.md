# El museo de la niña que amo 💜

Proyecto romántico interactivo hecho con HTML, CSS y JavaScript.

## Cómo abrirlo
1. Descarga y descomprime la carpeta.
2. Abre la carpeta `museo_nina_que_amo` en Visual Studio Code.
3. Abre `index.html` en tu navegador. También puedes usar la extensión Live Server.

## Música
Coloca un archivo MP3 que tengas derecho a utilizar en `assets/audio/` y nómbralo exactamente:
`chachacha.mp3`

El navegador solo permitirá iniciar la música después de que la visitante pulse el botón de entrada. Si el archivo no está colocado, el museo seguirá funcionando sin música.

## Fotografías
Coloca seis fotografías en `assets/fotos/` con estos nombres:
- `cualidad-01.jpeg`
- `cualidad-02.jpeg`
- `cualidad-03.jpeg`
- `cualidad-04.jpeg`
- `cualidad-05.jpeg`
- `cualidad-06.jpeg`

Las fotografías se muestran directamente en cada sala del museo.

## Publicar en GitHub Pages
Sube los archivos de esta carpeta al repositorio y activa GitHub Pages desde Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
